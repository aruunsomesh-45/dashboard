🛍️ Shopify Integration Guide

Connect your Shopify store to automatically sync orders, gross/net sales, average order value (AOV), and customer retention data.

⚠️ Critical Pitfall (Avoid 401 Unauthorized):
Shopify generates two different credentials:
  • Admin API Access Token starts with shpat_ (This goes into the Access Token field).
  • API Secret Key starts with shpss_ (This goes into the Webhook Secret field).
Do not paste the shpss_ secret into the Access Token field, or Shopify will reject it with 401 Unauthorized!

Parameters Required

Field in 125East Required? Expected Format Where to Find It
Shopify Store Domain Required your-store.myshopify.com Your browser address bar or Shopify Admin → Settings → Domains
Admin API Access Token Required shpat_xxxxxxxxxxxxxxxxxxxx Custom App → API credentials → Admin API access token
Webhook HMAC Secret Optional shpss_xxxxxxxxxxxxxxxxxxxx Custom App → API credentials → API secret key

Step-by-Step Procedure

  1. Open Shopify Admin Settings
    Go to admin.shopify.com and sign in. Click Settings (⚙️ bottom-left corner).
  2. Enable Custom App Development
    Click Apps and sales channels in the settings menu. Click Develop apps at the top right. (If prompted, click "Allow custom app development").
  3. Create the Custom App
    Click Create an app. Enter App Name: 125East Dashboard, select your email, and click Create app.
  4. Select Scopes (Permissions)
    In the Overview tab, click Configure Admin API scopes. Search and check:
    • ☑️ read_orders (Pulls orders and revenue)
    • ☑️ read_customers (Pulls buyer analytics)
    • ☑️ read_products (Pulls SKU & catalog sales)
    Click the black Save button in the top right.
  5. Install App and Copy the Token
    Switch to the API credentials tab. Click Install app and confirm. Under Admin API access token, click Reveal token once. Copy the token starting with shpat_.
  6. Connect in 125East
    Open 125East Integrations, expand the Shopify card, paste your Store Domain and shpat_ token, and click Save & Connect! Then click Sync Now 🔄.

💳 Razorpay Integration Guide

Sync payment settlement rates, refunds, customer payment failures, and bank chargebacks/disputes with zero manual reconciliation.

💡 Live Mode vs Test Mode:
Make sure you are toggled to Live Mode in your Razorpay Dashboard before generating keys. Live keys begin with rzp_live_. Test keys (rzp_test_) will only display fake dummy data.

Parameters Required

Field in 125East Required? Expected Format Where to Find It
Key ID Required rzp_live_xxxxxxxxxxxx Razorpay Dashboard → Account & Settings → API Keys
Key Secret Required xxxxxxxxxxxxxxxxxxxxxxxx Revealed once upon generating or downloading Key Details
Webhook Secret Optional rzp_wh_secret_xxxxxxx Created when setting up an instant webhook in Razorpay

Step-by-Step Procedure

  1. Open Razorpay API Keys Settings
    Log in to the Razorpay Dashboard API Keys page. Ensure the toggle in the top navbar is set to Live Mode.
  2. Generate Key Pair
    Click Generate Key (or Regenerate Key if you already have one). A popup will display your Key ID and Key Secret. Download or copy both strings immediately.
  3. (Optional) Set Up Instant Webhooks
    Go to Razorpay Webhooks. Click Add New Webhook:
    • Webhook URL: https://125east-dashboard.vercel.app/api/webhooks/razorpay/<your-brand-id>/
    • Secret: Choose any random password (e.g. my_razorpay_secret_123).
    • Active Events: Check payment.captured, payment.failed, refund.processed.
  4. Save in 125East
    Open 125East Integrations, expand the Razorpay card, paste your rzp_live_ Key ID and Secret, and click Save & Connect.

🚚 Delhivery / Logistics Guide

Connect Delhivery to track real-time AWB delivery status, transit stages, RTO returns, and Non-Delivery Report (NDR) reattempts.

Parameters Required

Field in 125East Required? Expected Format Where to Find It
Client ID / Account Name Required merchant_account_name Delhivery One Portal → Profile / Account Settings
API Token Required Bearer token (40-char string) Delhivery One Portal → Settings → API Keys

Step-by-Step Procedure

  1. Log in to Delhivery One Portal
    Navigate to Delhivery One Portal. Sign in with your registered merchant credentials.
  2. Navigate to API Settings
    Go to Settings → API & Integrations (or Developer Settings).
  3. Copy Your Client Name and API Token
    Copy your registered Client Name (e.g., YOURCOMPANY_EXPRESS) and the production API Token.
  4. Connect in 125East
    Open 125East Integrations, expand the Delhivery card, paste your Client Name and API Token, and click Save & Connect.

📢 Meta Ads (Facebook & Instagram Ads)

Pull daily ad spend, ROAS, cost per acquisition (CAC), click-through rate (CTR), and attribution metrics directly from Meta Ads Manager.

⚠️ Never Use Short-Lived User Tokens:
Standard Facebook user tokens expire in 1 to 2 hours! To ensure your dashboard updates continuously without breaking, create a System User Token in Meta Business Suite, which never expires.

Parameters Required

Field in 125East Required? Expected Format Where to Find It
Ad Account ID Required act_xxxxxxxxxxxxxxxx Meta Ads Manager URL (e.g. act_1234567890)
System User Access Token Required EAABxxxxxxxxxxxxxxxxxxxx Business Settings → System Users → Generate New Token

Step-by-Step Procedure

  1. Find Your Ad Account ID
    Open Meta Ads Manager. In the top-left account dropdown or browser URL, look for the account ID. Include the act_ prefix (e.g. act_1029384756).
  2. Open Meta Business Settings
    Go to Meta Business Settings → System Users. If you don't have a System User, click Add, set Role as Admin, and name it 125East Sync.
  3. Assign Assets to System User
    Click Add Assets on your System User. Under Ad Accounts, select your store's Ad Account, toggle on Full Control / Manage Ad Account, and click Save Changes.
  4. Generate Never-Expiring Token
    Click Generate New Token. Select your app, set token expiration to Never, and check these permissions:
    • ☑️ ads_read
    • ☑️ read_insights
    Click Generate Token and copy the string starting with EAAB....
  5. Connect in 125East
    Open 125East Integrations, expand Meta Ads, paste your act_ account ID and EAAB... token, and click Save & Connect!

📸 Organic Instagram Account Guide

Sync organic post performance, follower engagement rate, reach, and organic impressions from your brand's Instagram profile.

💡 Account Prerequisite:
Instagram's official API requires your Instagram account to be a Professional Account (Business or Creator) and linked to a Facebook Page you manage. Personal profiles are not supported by Meta's Graph API.

Step-by-Step Procedure

  1. Switch to a Professional Account in Instagram App
    In the Instagram mobile app, go to Profile → Settings & Privacy → Account type and tools → Tap Switch to professional account (Choose Business).
  2. Connect Instagram to Your Facebook Page
    In Instagram settings, tap Linked Accounts / Business Profile → Connect your store's Facebook Page.
  3. Generate Instagram Graph API Token
    In Meta Business Settings → System Users, click Generate New Token and ensure the following permissions are granted:
    • ☑️ instagram_basic
    • ☑️ instagram_manage_insights
    • ☑️ pages_show_list
    • ☑️ pages_read_engagement
  4. Save in 125East
    Open 125East Integrations, expand Instagram, enter your handle (e.g. @yourbrand) and token, and click Save & Connect.

❓ Master FAQs & Troubleshooting

1. Why do I get "Shopify rejected the Admin API Access Token (401 Unauthorized)"?
This almost always happens when you paste the API secret key (which begins with shpss_) into the Admin API Access Token box instead of the actual token (which begins with shpat_).

Fix: In Shopify Admin → Apps and sales channels → Develop apps → Your App → API credentials, look at the top box titled Admin API access token. Click Reveal token once to copy the token starting with shpat_.
2. Do I need to set up webhooks right now to see my orders?
No! You can leave the Webhook Secret empty initially. When you click Sync Now in your 125East dashboard, the backend automatically calls the Shopify REST API to pull the past 90 days of order and customer data into your database. Webhooks are only necessary later if you want instant, real-time push whenever a new order is completed.
3. Why are my Razorpay payments not showing up?
Check two things:
  1. Are you using rzp_test_... keys? Test keys will only pull sandbox transactions. Generate rzp_live_... keys from Razorpay Dashboard Live Mode.
  2. Ensure you copied the entire Key Secret without trailing spaces.
4. Why does my Meta Ads token stop working after a few days?
Tokens created through the Graph API Explorer or standard user login expire in 1–2 hours or 60 days. You must generate a System User Token inside Meta Business Settings. System user tokens do not have an expiration date.
5. How do I know if my data has been pulled successfully?
You can check in 2 places:
  • In Dashboard UI: The integration card will show 🟢 Connected and a timestamp like "Last synced: Today at 2:15 PM". Then click the Shopify tab in the sidebar to see your sales graphs.
  • In Terminal: Run .\.venv\Scripts\python.exe backend/check_data_sync.py. It outputs the exact count of orders, shipments, and ad rows saved in your database.
6. Is my API data and keys stored securely?
Yes. All external API keys and secrets are encrypted at rest using industry-standard AES-256-GCM encryption in PostgreSQL before they ever touch the database disk. No plain-text tokens are visible in database logs.
