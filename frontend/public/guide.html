🏁 Start Here: How the Dashboard Works (for beginners)

This dashboard shows your sales, payments, ad results and deliveries in one place. It gets that information from your other apps (Shopify, Razorpay, Delhivery, Meta). To let it do that, you give it a few keys, one for each app. Think of a key as a password that lets the dashboard read your app's information. Nothing else is needed.

Words you will see:
  • Key / token / secret: a long random text that proves the dashboard is allowed in. Keep it private.
  • Copy: select the text and press Ctrl + C (on Mac: Cmd + C). Paste it with Ctrl + V.
  • Connect / Save & Connect: saves your keys in the dashboard, where they are locked up (encrypted).
  • Sync: asks the app for its latest information and fills your dashboard.

Step 1: Open the dashboard

  1. Go to the website
    Open https://125east.vercel.app/login in Chrome. Sign in with your email and password.
  2. Open the connections page
    In the left menu, click Connect Apps. Direct link: https://125east.vercel.app/integrations. You will see one card for each app.

Step 2: Know what happens on each card

Card statusWhat it meansWhat to do
Not ConnectedNo keys saved yet.Follow that app's tab in this guide.
ConnectedKeys saved and working.Press Sync to refresh the data.
Sync ErrorKeys were rejected or expired. The reason is written on the card.Create a new key and save it again.
⚠️ Safety rules:
  • Never send a key by email, WhatsApp, or to anyone who asks for it.
  • Never paste keys into this guide, a chat, or a screenshot you share.
  • If a key leaks, delete it in that app and create a new one. Then save the new one in the dashboard.

🛍️ Shopify: orders, customers and sales

Connects your Shopify store so the dashboard can read orders, refunds, and customers.

The keys you need

Field on the cardLooks likeRequired?What it is
Shopify Store Domainyour-store.myshopify.comRequiredYour store's web address. Copy it from the top of your Shopify admin page, or from the address bar.
Admin API Access Tokenshpat_…RequiredThe password that lets the dashboard read your store. Shown once when you install the app.
Webhook HMAC Secretshpss_…OptionalLets the dashboard check that new orders really came from Shopify. Found on the same page as the token. Its name in Shopify is "API secret key".
Common mistake: the shpss_ key goes in the secret box. The shpat_ token goes in the token box. Putting them the wrong way round gives a "401 Unauthorized" error.

Step A: create the key in Shopify

  1. Open Shopify admin
    Go to admin.shopify.com and sign in to your store.
  2. Go to Settings
    Click Settings (the gear icon, bottom left). Then click Apps and sales channels.
  3. Turn on custom apps
    Click Develop apps (top right). If it asks, click Allow custom app development.
  4. Create the app
    Click Create an app. Name it 125East Dashboard. Click Create app.
  5. Choose what the app may read
    Click Configure Admin API scopes. Tick read_orders, read_customers and read_products. Click Save.
  6. Install and copy the token
    Click the API credentials tab, then Install app. Under Admin API access token, click Reveal token once. Copy the shpat_ token and save it in Notepad. Copy the API secret key (shpss_) too.

Step B: connect it in the dashboard

  1. Open the Shopify card
    Go to Connect Apps. Click Configure (or Connect Shopify) on the Shopify card.
  2. Paste the three values
    Store Domain → your-store.myshopify.com. Access Token → shpat_…. Webhook Secret → shpss_….
  3. Save
    Click Save & Connect. Wait for "Credentials encrypted & stored". Then click Test. The card should show Connected.
  4. Add the webhook (so new orders arrive automatically)
    In the dashboard, go to Settings and copy the Shopify Webhook URL. In Shopify admin: Settings → Notifications → Webhooks → Create webhook. Event: Order creation. Format: JSON. Paste the URL and save.
  5. Pull the data
    Click Sync on the Shopify card. Then open Shopify Store in the left menu to see your orders and sales.

💳 Razorpay: payments and refunds

Connects Razorpay so the dashboard can show successful payments, failed payments, refunds, and how payments are split by method (UPI, card, and so on).

The keys you need

Field on the cardLooks likeRequired?What it is
Key IDrzp_test_… or rzp_live_…RequiredPublic part of the key. Shown on the API Keys page.
Key Secreta long random textRequiredPrivate part. Razorpay shows it only once, when you create the key.
Webhook Secretany long random text you chooseRequired for live updatesYou make this up and enter it in both Razorpay and the dashboard. It proves that a message really came from Razorpay.
Tip: start with rzp_test_ keys (test mode, no real money). Switch to rzp_live_ keys after Razorpay approves your account.

Step A: create the keys in Razorpay

  1. Open the Razorpay dashboard
    Go to dashboard.razorpay.com and sign in.
  2. Open API Keys
    Click Account & Settings (bottom of the left menu), then API Keys.
  3. Generate the key
    Click Generate Key. Read the warning and confirm. Razorpay shows a Key ID and a Key Secret.
  4. Copy both values now
    Copy the Key ID and the Key Secret into Notepad. The secret cannot be shown again. If you lose it, generate a new key.
  5. Create the webhook secret
    Make up a long password, for example 30 random letters and numbers. Save it in Notepad. You will use it in two places.
  6. Create the webhook in Razorpay
    Go to Account & Settings → Webhooks → Add New Webhook. Paste the Razorpay Webhook URL from the dashboard's Settings page. Paste your webhook secret. Tick payment.captured, payment.failed and refund.processed. Save.

Step B: connect it in the dashboard

  1. Open the Razorpay card
    Go to Connect Apps and click Connect Razorpay.
  2. Paste the three values
    Key ID → rzp_…. Key Secret → the secret. Webhook Secret → the password you made up.
  3. Save and test
    Click Save & Connect, then Test. The card should show Connected.
  4. Pull the data
    Click Sync, then open Payments in the left menu.

🚚 Delhivery: deliveries and shipment status

Connects Delhivery so the dashboard can show where your parcels are, which were delivered, and which failed or were returned.

The keys you need

Field on the cardLooks likeRequired?What it is
Client ID / Account CodeDLH_… (your account)Optional for nowYour Delhivery account reference. The dashboard does not use it yet. Ask Delhivery for it if you can't find it.
API Tokena long random textRequiredThe password that lets the dashboard read your shipments.
Webhook Secret Key—Not used yetLeave it empty.

Step A: create the token in Delhivery One

  1. Sign in to Delhivery One
    Sign in at Delhivery One (the Delhivery business portal). Your account must be set up first: business details, KYC, and at least one pickup location. Delhivery's getting-started guide explains this.
  2. Open API Setup
    Click Main Menu → Settings → API Setup. This is the menu path in Delhivery's token guide.
  3. Get the token
    If you can see a token, click the copy button next to it. If you don't have one, click Request Live API Token.
  4. Save it straight away
    Delhivery shows the token for only 5 minutes, and you can reveal it only once. Paste it into Notepad at once.
Important: generating a new token makes the old one stop working immediately. If another system uses the old token, update it there as well.

Step B: connect it in the dashboard

  1. Open the Delhivery card
    Go to Connect Apps and click Connect Delhivery Logistics.
  2. Paste the values
    Client ID → your account reference (or your account name if you don't have it yet). API Token → the token you copied. Leave the webhook box empty.
  3. Save and test
    Click Save & Connect, then Test. You should see Connected. "rejected the API token" means the token is wrong or it's a staging token.
  4. Pull shipment data
    Open Logistics in the left menu. In the box called Sync Delhivery shipments, type the waybill numbers (AWB numbers) of your parcels, one per line or separated by commas. Click Sync shipments.
Where do waybill numbers come from? Each parcel you ship gets one (usually 10 to 12 digits). It appears on the shipping label and in Delhivery One. Once synced, the dashboard refreshes those parcels on its own.

📢 Meta Ads: Facebook and Instagram ads

Connects your ad account so the dashboard can show spend, clicks, purchases and return on ad spend (ROAS) by day and by campaign.

The keys you need

Field on the cardLooks likeRequired?What it is
Ad Account IDact_1234567890RequiredThe number of your ad account. Starts with act_.
System User Access TokenEAAB…RequiredThe password that lets the dashboard read your ads. Use a system user token set to never expire. A normal token expires every day.
Why a system user? Tokens made from the Graph API Explorer or your personal login expire within hours or days. The sync then fails with "Session has expired". A system user token does not expire.

Step A: find your Ad Account ID

  1. Open Ads Manager
    Go to adsmanager.facebook.com. Pick the right ad account at the top left.
  2. Copy the number
    Look at the web address. It contains act=…. The number after act= is your ID. Write it as act_ followed by that number.

Step B: create a never-expiring token

  1. Open Business Settings
    Go to business.facebook.com/settings.
  2. Create a system user
    Click Users → System users → Add. Name it 125east-dashboard. Role: Admin. Click Create system user.
  3. Give it your ad account
    Select the system user. Click Add assets → Ad accounts. Tick your ad account and turn on View performance. Click Save changes.
  4. Generate the token
    With the system user still selected, click Generate new token. Choose your app. Tick ads_read. Set the expiration to Never. Click Generate token.
  5. Copy it now
    Copy the token into Notepad. Meta shows it only once.

Step C: connect it in the dashboard

  1. Open the Meta Ads card
    Go to Connect Apps and click Configure on the Meta Ads card.
  2. Paste the two values
    Ad Account ID → act_…. System User Access Token → the EAAB… token.
  3. Save and test
    Click Save & Connect, then Test. The card should show Connected.
  4. Pull the campaigns
    Open Marketing & Ads and press Sync Data. The first sync fetches up to a year of history, one month at a time, so it can take a few minutes. Keep the page open. Then choose Last 30 Days or All-Time to see the numbers.

📸 Instagram: your organic account

Checks that the dashboard can reach your Instagram business account. Daily follower and reach numbers are not shown yet.

The keys you need

Field on the cardLooks likeRequired?What it is
Instagram Business Handle@yourbrandRequiredYour Instagram username.
Graph API User TokenEAAB…RequiredThe password that lets the dashboard read your account. Use a token from your system user (the same method as Meta Ads).
Before you start: your Instagram account must be a Business or Creator account, linked to a Facebook Page. In Instagram: Settings → Account type and tools → Switch to professional account.

Step A: create the token

  1. Use the same system user
    Follow Meta Ads Step B above. When you generate the token, also tick instagram_basic and pages_read_engagement, with expiration Never.
  2. Give the system user your Instagram account
    In Business Settings, select the system user → Add assets → Instagram accounts → tick your account → Save changes.

Step B: connect it in the dashboard

  1. Open the Instagram card
    Go to Connect Apps and click Connect Instagram Organic.
  2. Paste the two values
    Handle → @yourbrand. Graph API User Token → the EAAB… token.
  3. Save and test
    Click Save & Connect, then Test. Connected means the dashboard can see your account.

❓ Help & FAQs

What do the error messages mean?

Message on the cardWhat it meansWhat to do
"Shopify rejected the Admin API token (401)"The shpat_ token is wrong, or the app was removed.Reveal the token again in Shopify and save it.
"Session has expired"The Meta token has run out.Make a system user token set to Never expire (Meta Ads tab).
"Razorpay rejected the API key/secret"Key ID and Key Secret don't match, or the key was deleted.Generate a new key pair in Razorpay and save both values.
"Delhivery rejected the API token"The token is wrong, or a newer token replaced it.Copy the current token from Delhivery One → Settings → API Setup.
"Backend server is temporarily unavailable"A short service problem.Wait a minute and try again.

Common questions

Why is the dashboard empty? ▾
The card must say Connected, and you must press Sync once. Empty history for the all-time view means the first Meta sync hasn't finished.
Do I need to sync every day? ▾
No. The dashboard refreshes Shopify, Razorpay and Meta every few hours on its own. You only need Sync after connecting, or if you want the latest numbers right now.
Can I see my own keys again? ▾
No, and that's by design. The dashboard stores them encrypted and never shows them. To change one, paste a new value into the card and press Save & Connect.
Is this safe? ▾
Keys are encrypted before they are saved, and only the server can read them. Your dashboard login uses two-factor authentication if you turn it on.
