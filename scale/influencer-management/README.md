# 125East Influencer & Creator Attribution Module (Scale Module)

## Overview
This directory contains the Influencer Management and Creator Marketing interface.

## Features
- Creator ROI & blended ROAS calculation.
- Coupon code redemptions and revenue attribution.
- Instagram tag and creator engagement metrics.
- Campaign parameter (UTM) analysis.

## Re-integration Instructions
1. Copy `app/influencer/` to `frontend/src/app/influencer/`.
2. Add navigation item `{ name: "Influencer", href: "/influencer", icon: Award }` back into `frontend/src/components/layout/DashboardShell.tsx`.
